A StackChan desk companion for coding, focus sessions and music, with optional conversations through AirPods.

Firmware + a local Mac bridge + a native control panel. Task sync uses USB or Bluetooth without robot Wi-Fi. Tasks, timers, notes, music metadata and local vision make no cloud-model calls. **Optional voice uses the factory cloud service, Mac internet access and your own valid device identity. It does not use a Codex subscription; pricing and long-term quotas remain unknown.** This independent project is not affiliated with M5Stack or OpenAI.

**Experimental v0.48 · updated October 19, 2026.** This is a source update, without a signed/notarized Mac installer or prebuilt firmware. QQ Music display and pause/play were verified on hardware; NetEase playback and the natural return-to-work flow still await hands-on acceptance.

## What changed

- **Local Mac app**: migrate an existing installation to `/Applications/微光控制台.app`, with Spotlight, Dock and native menus. Optional voice/vision components live in a fixed per-user data directory rather than the development checkout. System dependencies are still required.
- **Motion recovery**: for eligible faults, save evidence and check torque release, position and stillness over BLE before restoring motion. No test nod, robot reboot or Pomodoro reset; existing safety limits remain.
- **Main-session notifications**: exclude subagents and background approval threads. Notify once after an explicit end remains final for about one second; pending questions, immediate continuation, duplicate events and reconnection do not replay old completions.

## Features

- **Tasks and return recap:** up to eight recently active Codex conversations, progress, waiting states and results. After a lock/absence of at least 30 seconds, show currently waiting tasks and reliably observed new results.
- **Quiet alerts:** amber indicators and expressions. Hold a waiting card for about 0.9 seconds to open its Codex conversation without releasing your finger.
- **Companion:** default/cat faces, blush, optional small head-touch nods, blinks, yawns and closed-eye rest without dimming.
- **Focus and notes:** 15/25/45-minute progress-ring timer, five-minute breaks, daily totals and one persistent warm-yellow note of up to 32 characters.
- **Music:** QQ Music/NetEase metadata, progress and previous/play-pause/next controls. A small face animation uses screen motion only.
- **AirPods voice:** streaming replies, continuous conversation, interruption, chat bubbles, a compact floating call UI and global shortcut. Optional connection greetings and task-completion notices.
- **Voice actions:** start/pause/resume/end a timer or write a note while explicitly in voice mode.
- **Experimental local vision:** robot camera over USB to Apple Vision on Mac; smiles, on-screen gaze and wave responses. No image storage/upload or physical head tracking.
- **Native console:** Workbench, Robot, Conversation and Connection tabs, appearance previews, expandable settings and explicit save feedback.

Voice only plays while the bound AirPods are the actual output. Disconnection, route changes or uncertainty stop playback without speaker fallback. The factory role controls the voice; the development device's owner confirmed “湾湾小何v2”. No voice model, account or entitlement is distributed.

## Requirements and setup

Target: **M5Stack StackChan K151 / CoreS3 / ESP32-S3, 16 MB Flash**, macOS 12+, Python 3.9+, Xcode Command Line Tools and a USB data cable. Current hardware testing used macOS 15.6.1; new features and the external music utility are not verified on every older OS. The UI is primarily Chinese.

This replaces the stock application/menu. Back up **your own** complete factory Flash, partition table and calibration first. Never flash someone else's complete backup. Optional Mac voice integration is experimental, not full restoration of factory functionality.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install platformio==6.2.0
.venv/bin/python -m pip install --no-index --require-hashes -r bridge/requirements.txt --find-links bridge/wheels
.venv/bin/pio run
python3 macos/build.py
python3 macos/build_icon.py
python3 macos/build_panel.py
```

The first firmware build downloads pinned dependencies. Native scripts build universal arm64/x86_64 development binaries with local ad-hoc signing, not a notarized release. See [development notes](docs/DEVELOPMENT.md).

Read [hardware and flashing boundaries](docs/HARDWARE.md) before using `.pio/build/stackchan/firmware.bin`. The tested device updates only the application at `0x10000`, preserving NVS/calibration. Do not use full PlatformIO upload or erase_flash as a generic installation procedure; verify your partition layout first.

With compatible firmware and USB connected:

```sh
./weiguang install
./weiguang status
./weiguang panel
./weiguang bind-bluetooth
```

Allow Bluetooth access for the helper. Installation is per-user, without sudo. Bluetooth task sync needs no office Wi-Fi; camera streaming still requires USB.

### Optional features

- **Music:** `brew install media-control`, then enable music in Workbench → Desk companion. Controls require AirPods output. QQ/NetEase and macOS retain ownership of music routing.
- **Return recap:** enabled by default; a home-screen entry appears when there is content. Sleep/disconnection gaps are marked rather than reconstructed as certain history.
- **Voice:** follow [AirPods setup](HEADPHONES_VOICE_SETUP.md) for your own backup, dependencies and binding. No microphone starts automatically. Task sync works without voice setup.
- **Vision:** explicitly enable Robot → “看见你”. See [local vision](VISUAL_INTERACTION.md). It starts off and stops on lock.

## Controls

| Action | Result |
| --- | --- |
| Tap home / swipe list | Browse tasks |
| Hold waiting card or recap row ~0.9 s | Open its Codex conversation, never auto-reply |
| Touch head | Expression and optional nod |
| Home → Music | Details and playback controls |
| Timer tap / Exit / End | Show controls / return home while timing / cancel cycle |
| Control + Option + Space | Enter/exit compact voice mode while console runs, subject to headphones and permissions |
| `./weiguang pause` / `resume` | Pause/resume sync |
| `./weiguang diagnostics` | Export diagnostics without task, note, music or chat content |

## Validation and limits

The public mirror is independently checked; see [development notes](docs/DEVELOPMENT.md). Automated tests and one development device do not guarantee other hardware or long-term stability. A completed turn is not proof that an entire project is finished.

Codex local storage, private macOS media interfaces and the factory voice service can change. Base tasks/timers/notes require no model service; factory voice cannot be promised free forever.
