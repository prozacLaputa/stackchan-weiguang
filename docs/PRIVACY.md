# 数据与局限

桥接读取当前用户本机 Codex 的会话数据库与日志，自动选择最近活跃的最多 8 个会话。它依赖本地存储格式，不是 OpenAI 稳定公开 API；应用升级可能需要兼容调整。

任务标题、状态、短进展、待答摘要与完成摘录会发给你绑定的设备，并显示在屏幕上。任务显示不是内容脱敏器；工位上不宜展示时，可暂停同步并关闭设备显示。日志和诊断导出采用字段白名单，不包含完整聊天或便签正文。

便签正文位于机器人 NVS 和 Mac 本地受限权限状态快照。收起只是改变展示状态，保留正文供重新贴上，不等于安全擦除。未贴出的草稿只存在控制台内存中。

基础任务同步不访问模型 API；USB／BLE 连接只传本机状态和控制消息。蓝牙使用经 USB 写入的绑定密钥，并实现 AES-256-GCM 应用层加密、连接挑战派生密钥和序号防重放；这套实现未经独立安全审计。不要在便签中保存密码等秘密。

Mac 安装位置为当前用户的 `~/Library/Application Support/Weiguang/`；运行状态、配置与绑定留在本机。公开副本服务标识为 `io.github.prozaclaputa.weiguang`。迁移包不带当前绑定密钥或会话；可选的完整工厂备份只供私人归档。

`./weiguang uninstall` 关闭并移除登录服务，保留用户资料和固件；如需清理数据，先自行备份，再处理对应本地文件和设备存储。


## 可选模块

- 工作接力只比较可确认的 Top8 状态，睡眠断连可能不完整；进程内记录及权限 600 的当前快照，不建立长期历史。
- 音乐只读取 QQ／网易云当前发布的媒体元数据；不读取账号、Cookie、音频或封面。锁屏停止，曲名和接力条目不进入诊断导出。
- 视觉画面只在 USB、管道和内存中，由 Apple Vision 本地处理；不保存／上传，默认关闭，锁屏停采。
- 语音明确使用原厂云服务：文字／主动录音会上传；任务播报打开后允许发送任务名称。原厂侧的保存及费用不由本项目控制。接入凭据仅从用户自己的校验备份在内存中读取，公开仓库不含任何备份、设备身份或服务账号。
- 本地对话／回复音频不落盘；输入合成临时文件编码后删除。耳机 UID 和开关留在本机，不随普通迁移导出。语音指定已绑定 AirPods 输出，不回退扬声器；音乐应用自身的路由不由这个播放器保护。

功能配置、故障阶段／计时及当前状态仍可在本地保存；“正文不进入诊断”不等于机器上完全没有运行痕迹。不要公开上传自己的备份、迁移包或运行目录。
